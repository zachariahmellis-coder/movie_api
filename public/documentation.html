🎬 myFlix API Documentation

The myFlix API is a RESTful backend built with Node.js, Express, MongoDB, and Mongoose. It provides endpoints for movies, genres, directors, and user accounts (including favorites).

Base URL

http://localhost:3000

Docs route: /documentation (redirects to /documentation.html)

Data Models (Mongoose)

Movie

{
  "_id": "ObjectId",
  "Title": "String (required)",
  "Description": "String (required)",
  "Genre": {
    "Name": "String (required)",
    "Description": "String (required)"
  },
  "Director": {
    "Name": "String (required)",
    "Bio": "String (required)",
    "Birth": "String (optional)",
    "Death": "String (optional)"
  },
  "ImagePath": "String (required)",
  "Featured": "Boolean (default: false)",
  "Actors": ["String"],
  "ReleaseYear": "Number (optional)",
  "Rating": "String (optional)",
  "createdAt": "Date",
  "updatedAt": "Date"
}

User

{
  "_id": "ObjectId",
  "Username": "String (required, unique)",
  "Password": "String (required)",
  "Email": "String (required, unique)",
  "Birthday": "Date (optional)",
  "FavoriteMovies": ["ObjectId (ref: Movie)"],
  "createdAt": "Date",
  "updatedAt": "Date"
}

Note: Some endpoints return FavoriteMovies populated with full Movie documents (not just ObjectIds).

Note: Passwords are stored in plain text for this project; authentication and hashing will be implemented in a later iteration.

Endpoint Details

GET /health Implemented

Description: Verifies MongoDB connection status via Mongoose.

This endpoint is provided for development and testing convenience.

Response Example:

{
  "ok": true,
  "mongoState": 1
}

GET /movies Implemented

Description: Returns a list of all movies.

GET /movies/:title Implemented

Description: Returns a single movie by title.

Matching: Case-insensitive exact title match.

GET /genres/:name Implemented

Description: Returns the embedded Genre object from the first movie matching the provided genre name.

Matching: Case-insensitive exact match on Genre.Name.

GET /directors/:name Implemented

Description: Returns the embedded Director object from the first movie matching the provided director name.

Matching: Case-insensitive exact match on Director.Name.

GET /users Implemented

Description: Returns all users with FavoriteMovies populated with Movie documents.

POST /users Implemented

Description: Registers a new user.

Notes: Username and Email must be unique.

PUT /users/:username Implemented

Description: Updates a user (by existing username).

POST /users/:username/movies/:movieId Implemented

Description: Adds a movie ObjectId to FavoriteMovies.

Notes: Uses $addToSet (prevents duplicates) and returns populated favorites.

DELETE /users/:username/movies/:movieId Implemented

Description: Removes a movie ObjectId from FavoriteMovies.

Notes: Uses $pull and returns populated favorites.

DELETE /users/:username Implemented

Description: Deregisters (deletes) a user by username.

Response Example:

username was deleted.
